# Full-stack e-commerce site

(NL)
Dit project richt zich op het bouwen van een complete full-stack webshop. 
Ik maak gebruik van Python (Django) en PostgreSQL voor de backend en React (Next.js) met Tailwind CSS voor de frontend.

(EN)
This project focuses on building a complete full-stack e-commerce site. 
I am using Python (Django) and PostgreSQL for the backend, and React (Next.js) with Tailwind CSS for the frontend.
